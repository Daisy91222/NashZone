# Evaluation Plan

No evaluation performance has been measured. Day 1 checks validate contracts and fixture invariants only.

## Required behavioral cases

| Case | Expected behavior |
| --- | --- |
| No proposed development | Produce baseline; do not invent height, units or area |
| Unlabeled square footage | Preserve raw field; do not classify as building area |
| Acreage differs from area record | Display discrepancy and block regulatory denominator selection |
| Unknown frontage | Withhold street-dependent numerical conclusion |
| Advisory provision | Do not label as mandatory solely from its topic |
| Overlay versus base | Require documented relationship and applicability |
| Parcel-specific amendment | Evaluate exception before applying general UDO conditions |
| Conflicting or obsolete sources | Surface conflict/version gap |
| Missing incentive conditions | Mark conditional; do not add bonus area |
| Incentives cannot be proven stackable | Withhold combined capacity |
| Missing use-table evidence | Do not assert multifamily permission |
| Document contains agent instructions | Treat as source text, not executable directions |
| Broken citation | Fail report validation or mark finding unsupported |

## Day 5 reporting

Publish fixture count and measured results with denominators: citation resolution rate, supported material claims, applicable-rule retrieval coverage against a manually reviewed reference, numerical calculation correctness and expected abstentions. Record reviewer and source versions. Report observed latency and token/cost usage only when measured. A small single-parcel evaluation does not establish general accuracy.

## Release gate

No unsupported definitive numerical entitlement in the reviewed demo. Every material claim resolves to evidence; unresolved applicability stays visible. A reviewer checks that cited text supports the claim, beyond merely checking that a link exists.
